# NetworkWalks – Week 2 Cybersecurity Lab

## Overview

This repository contains my Week 2 cybersecurity internship lab report at NetworkWalks, completed using Kali Linux in an authorized lab environment.

The exercises covered network reconnaissance, OSINT, and network scanning.

## Activities

### 1. Network Footprinting
Used the following tools to gather publicly available information about networkwalks.com:

- WHOIS
- WhatWeb
- Nslookup
- cURL
- Wafw00f
- DNSRecon

Identified domain registration details, name servers, web technologies, WAF information, and DNS and email records.

### 2. OSINT with Maltego
Used Maltego to investigate the domain and identify publicly exposed contact information through a domain transform.

### 3. Network Discovery with Nmap
- Identified the local IP address and LAN subnet.
- Performed host discovery using Nmap.
- Identified the detected live host and its MAC address.
- Created a network topology.

## Tools and Environment

- Kali Linux
- Nmap
- Maltego
- WHOIS, WhatWeb, Nslookup, cURL, Wafw00f, DNSRecon
